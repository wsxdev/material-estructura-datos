1. Análisis de Algoritmos

Complejidad Temporal y Espacial

La complejidad de un algoritmo mide cuántos recursos (tiempo y memoria) consume en relación al tamaño de la entrada.

Tipos:

  • Temporal: Número de operaciones realizadas
  • Espacial: Memoria auxiliar consumida

Big O Cheatsheet

Notación Nombre Ejemplo n=1000
O(1) Constante Acceso a array 1
O(log n) Logarítmica Búsqueda binaria 10
O(n) Lineal Búsqueda lineal 1,000
O(n log n) Lineal-log Merge Sort 10,000
O(n²) Cuadrática Bubble Sort 1,000,000
O(2^n) Exponencial Fuerza bruta 10³⁰

Estudio de Algoritmos Clásicos

Los algoritmos se analizan considerando:

  • Mejor caso: Entrada más favorable
  • Caso promedio: Entrada típica
  • Peor caso: Entrada más desfavorable

2. Algoritmos de Ordenamiento

Ordenamiento Burbuja (Bubble Sort)

Compara elementos adyacentes e intercambia si están en orden incorrecto. Repite hasta que no hay intercambios.

Características:

  • Complejidad: O(n²) peor caso, O(n) mejor caso
  • Espacio: O(1)
  • Estable: Sí
  • In-place: Sí

Implementación:

def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]

Quicksort

Algoritmo divide y conquista que selecciona un pivote y particiona el array. Luego ordena recursivamente las particiones.

Características:

  • Complejidad: O(n log n) promedio, O(n²) peor caso
  • Espacio: O(log n)
  • Estable: No
  • In-place: Sí

Implementación:

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

Mergesort

Divide el array en mitades, ordena cada mitad y combina los resultados. Garantiza O(n log n) siempre.

Características:

  • Complejidad: O(n log n) todos los casos
  • Espacio: O(n)
  • Estable: Sí
  • In-place: No

Ventajas/Desventajas:

  • ✅ Garantizado O(n log n)
  • ✅ Estable
  • ❌ Requiere O(n) de memoria extra
  • ❌ Más lento que Quicksort promedio

Comparación de Ordenamientos

Algoritmo Mejor Caso Promedio Peor Caso Espacio Estable
Bubble Sort O(n) O(n²) O(n²) O(1) Sí
Quicksort O(n log n) O(n log n) O(n²) O(log n) No
Mergesort O(n log n) O(n log n) O(n log n) O(n) Sí

3. Algoritmos de Búsqueda

Búsqueda Secuencial

Recorre el array elemento por elemento hasta encontrar el objetivo o llegar al final.

Características:

  • Complejidad: O(n)
  • Ventaja: Funciona en arrays desordenados
  • Desventaja: Lenta para arrays grandes
def busqueda_secuencial(arr, objetivo):
    for i in range(len(arr)):
        if arr[i] == objetivo:
            return i
    return -1  # No encontrado

Búsqueda Binaria

Divide el array ordenado por la mitad en cada iteración, descartando la mitad que no puede contener el objetivo.

Características:

  • Complejidad: O(log n)
  • Requisito: Array debe estar ordenado
  • Ventaja: Muy rápida para arrays grandes
def busqueda_binaria(arr, objetivo):
    izquierda, derecha = 0, len(arr) - 1
    while izquierda <= derecha:
        medio = (izquierda + derecha) // 2
        if arr[medio] == objetivo:
            return medio
        elif arr[medio] < objetivo:
            izquierda = medio + 1
        else:
            derecha = medio - 1
    return -1

Búsqueda Hash (Tabla Hash)

Utiliza una función hash para mapear claves a índices en una tabla. Proporciona acceso promedio O(1).

Características:

  • Complejidad Promedio: O(1)
  • Peor Caso: O(n) (colisiones)
  • Espacio: O(n)
  • Ventaja: Acceso muy rápido

Aplicaciones:

  • Diccionarios y mapas
  • Caché
  • Búsqueda de duplicados

Comparación de Búsquedas

Algoritmo Complejidad Requisitos Uso Ideal
Secuencial O(n) Ninguno Arrays pequeños o desordenados
Binaria O(log n) Ordenado Arrays grandes ordenados
Hash O(1) prom. Tabla hash Búsquedas frecuentes

Resumen de la Unidad 4

  • Big O describe cómo escala un algoritmo con la entrada
  • Bubble Sort es simple pero ineficiente O(n²)
  • Quicksort es rápido O(n log n) promedio pero no garantizado
  • Mergesort es garantizado O(n log n) pero usa más memoria
  • Búsqueda binaria requiere array ordenado pero es muy rápida O(log n)
  • Hash proporciona acceso promedio O(1) en tablas
