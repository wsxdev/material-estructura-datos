1. Pilas (Stack)

¿Qué es una Pila?

Una pila es una estructura de datos lineal que sigue el principio LIFO (Last In, First Out): el último elemento añadido es el primero en salir.

Imaginemos una pila de platos: los platos se agregan y se retiran desde la parte superior.

Representación Gráfica

    Pila de enteros:
    
    Operación: push(5)  | push(10) | push(3)  | pop()   |
    
    Tope → [3]         | Tope → [3]    | Tope → [3] | Tope → [10]
           [10]        |         [10]   |        [10]|        [10]
           [5]         |         [5]    |        [5] |        [5]
           ----        |         ----   |        ----| ----

Operaciones

Operaciones Básicas

  • push(x): Inserta x en el tope
  • pop(): Elimina y retorna el tope
  • top(): Retorna el tope sin eliminar
  • isEmpty(): ¿Está vacía?

Complejidad

  • push(): O(1)
  • pop(): O(1)
  • top(): O(1)
  • isEmpty(): O(1)

Implementación en Python

class Pila:
    def __init__(self):
        self.items = []
    
    def push(self, item):
        self.items.append(item)
    
    def pop(self):
        return self.items.pop() if not self.isEmpty() else None
    
    def top(self):
        return self.items[-1] if not self.isEmpty() else None
    
    def isEmpty(self):
        return len(self.items) == 0

# Uso
p = Pila()
p.push(5)
p.push(10)
p.push(3)
print(p.pop())  # 3
print(p.top())  # 10

2. Colas (Queue)

¿Qué es una Cola?

Una cola es una estructura de datos lineal que sigue el principio FIFO (First In, First Out): el primer elemento añadido es el primero en salir.

Es como una fila de personas esperando: entra el primero y sale el primero.

Tipos y Representación Gráfica

Cola Simple

Inicio → [1] [2] [3] [4] ← Final

Encolar(5): [1] [2] [3] [4] [5]
Desencolar(): [2] [3] [4] [5]

Cola Circular

      [4] [5]
    [3]     [1]
    [2]     [*]

Optimiza el uso de memoria
reutilizando espacios

Operaciones

Operación Descripción Complejidad
enqueue(x) Inserta x al final O(1)
dequeue() Elimina y retorna el inicio O(1)
front() Retorna el inicio sin eliminar O(1)
isEmpty() ¿Está vacía? O(1)

Implementación en Python

from collections import deque

class Cola:
    def __init__(self):
        self.items = deque()
    
    def enqueue(self, item):
        self.items.append(item)
    
    def dequeue(self):
        return self.items.popleft() if not self.isEmpty() else None
    
    def front(self):
        return self.items[0] if not self.isEmpty() else None
    
    def isEmpty(self):
        return len(self.items) == 0

# Uso
c = Cola()
c.enqueue(1)
c.enqueue(2)
c.enqueue(3)
print(c.dequeue())  # 1
print(c.front())    # 2

3. Listas

¿Qué es un Nodo?

Un nodo es la unidad básica de una lista enlazada. Contiene:

  • Dato: El valor almacenado
  • Referencia/Puntero: Apunta al siguiente nodo
class Nodo:
    def __init__(self, dato):
        self.dato = dato
        self.siguiente = None

¿Qué es una Lista?

Una lista enlazada es una secuencia de nodos conectados por referencias. Permiten inserción y eliminación eficiente en posiciones arbitrarias.

Tipos y Representación Gráfica

Lista Simple

Inicio → [1|→] → [2|→] → [3|→] → [4|None]

Acceso secuencial
Eliminación O(n)

Lista Doble

[None|1|→] ← → [2|→] ← → [3|→] ← → [4|None]

Navegación bidireccional
Más memoria

Operaciones en Listas

Operación Lista Simple Lista Doble
Acceso O(n) O(n)
Inserción al inicio O(1) O(1)
Inserción en posición O(n) O(n)
Eliminación O(n) O(n)

Implementación de Lista Simple

class ListaSimple:
    def __init__(self):
        self.inicio = None
    
    def insertar_inicio(self, dato):
        nodo = Nodo(dato)
        nodo.siguiente = self.inicio
        self.inicio = nodo
    
    def insertar_final(self, dato):
        nodo = Nodo(dato)
        if self.inicio is None:
            self.inicio = nodo
            return
        actual = self.inicio
        while actual.siguiente:
            actual = actual.siguiente
        actual.siguiente = nodo
    
    def mostrar(self):
        actual = self.inicio
        while actual:
            print(actual.dato, end=" → ")
            actual = actual.siguiente
        print("None")
