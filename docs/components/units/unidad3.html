1. Visualización de Algoritmos

Importancia de la Visualización

La visualización de algoritmos es fundamental para comprender cómo funcionan estructuras complejas. Permite identificar patrones, errores y optimizaciones.

Herramientas Recomendadas

Herramientas Online

  • VisuAlgo.net - Visualización de algoritmos
  • Sorting Visualizer - Ordenamientos
  • Graph Online - Grafos interactivos

Bibliotecas de Programación

  • Graphviz - Renderizar grafos
  • Matplotlib - Python visualización
  • D3.js - Visualización web interactiva

Técnicas de Visualización

  • Diagramas de árbol: Mostrar estructura jerárquica
  • Grafos dirigidos: Relaciones y dependencias
  • Animaciones: Mostrar paso a paso la ejecución
  • Matrices de adyacencia: Representar conectividad

2. Árboles

Definición de Árbol

Un árbol es una estructura de datos no lineal que consiste en nodos conectados por aristas, donde existe un nodo especial llamado raíz y no existen ciclos.

Términos:

  • Raíz: Nodo sin padre
  • Hoja: Nodo sin hijos
  • Altura: Distancia máxima a una hoja
  • Nivel: Distancia desde la raíz

Representación

      Árbol Binario:
      
            A
           / \
          B   C
         / \   \
        D   E   F
        
Raíz: A
Hojas: D, E, F
Altura: 2

Recorridos en Árboles

Recorridos en Profundidad

  • Preorden: A, B, D, E, C, F
  • Inorden: D, B, E, A, C, F
  • Postorden: D, E, B, F, C, A

Recorridos en Amplitud

  • BFS (Breadth-First): A, B, C, D, E, F

Tipos Especiales de Árboles

Árbol Binario de Búsqueda

Izquierda < Raíz < Derecha, búsqueda O(log n)

Árbol AVL

Árbol binario balanceado, altura O(log n)

Árbol Rojo-Negro

Árbol binario con propiedades de balance

Métodos Comunes

Método Descripción ABB Promedio
búsqueda() Encontrar un elemento O(log n)
inserción() Agregar un elemento O(log n)
eliminación() Remover un elemento O(log n)
recorrido() Visitar todos los nodos O(n)

3. Grafos

Definición

Un grafo es una estructura de datos que consiste en vértices (nodos) conectados por aristas. Pueden tener ciclos, múltiples conexiones y ser no conexo.

Tipos de Grafos

Por Dirección

  • Grafo No Dirigido: Las aristas van en ambas direcciones
  • Grafo Dirigido (Digrafo): Las aristas tienen dirección

Por Peso

  • Grafo No Ponderado: Todas las aristas tienen peso 1
  • Grafo Ponderado: Las aristas tienen pesos variables

Propiedades

  • Orden: Número de vértices
  • Tamaño: Número de aristas
  • Grado: Número de aristas incidentes a un vértice
  • Camino: Secuencia de vértices conectados
  • Conexidad: Si existe camino entre todo par de vértices

Representaciones

Matriz de Adyacencia

Matriz n×n donde aij = 1 si existe arista (i,j)

Ventaja: Acceso O(1)

Desventaja: Espacio O(n²)

Lista de Adyacencia

Lista de listas para cada vértice

Ventaja: Espacio O(V+E)

Desventaja: Acceso O(grado(v))

Algoritmos en Grafos

Búsqueda

  • BFS: Amplitud primero
  • DFS: Profundidad primero

Recorridos Especiales

  • Dijkstra: Camino más corto
  • Floyd-Warshall: Todos los caminos

Repositorios de práctica (Grafos)

  • Grafos

Resumen de la Unidad 3

  • La visualización es esencial para entender estructuras complejas
  • Árboles son estructuras jerárquicas sin ciclos
  • Los recorridos permiten acceder a todos los nodos
  • Grafos generalizan árboles permitiendo ciclos
  • Existen múltiples representaciones y algoritmos para grafos
