1. Introducción

Historia de las Estructuras de Datos

Las estructuras de datos surgieron como necesidad fundamental en la informática para organizar y gestionar información de manera eficiente. Su evolución ha acompañado el desarrollo de los lenguajes de programación y la arquitectura de computadores.

  • 1950s-1960s: Primeras abstracciones de datos en lenguajes como FORTRAN y ALGOL
  • 1970s: Desarrollo de estructuras fundamentales: arrays, listas enlazadas, árboles
  • 1980s: Programación orientada a objetos y encapsulamiento de estructuras
  • 1990s-Presente: Estructuras avanzadas, garbage collection, y optimizaciones modernas

Características Principales

Eficiencia

Busca minimizar el tiempo de acceso, inserción y eliminación de datos

Memoria

Optimiza el uso del espacio en memoria disponible del sistema

Facilidad

Proporciona interfaces simples para manipular datos complejos

Ventajas y Desventajas

Ventajas

  • Mejoran la velocidad de acceso a datos
  • Permiten resolver problemas complejos
  • Facilitan el mantenimiento del código
  • Optimizan el uso de recursos
  • Base para algoritmos eficientes

Desventajas

  • Requieren mayor complejidad de implementación
  • Mayor curva de aprendizaje
  • Overhead de memoria en algunos casos
  • Selección incorrecta puede degradar rendimiento

2. Tipos de Datos

Tipos Primitivos de Datos

Son los tipos básicos que proporciona un lenguaje de programación:

Tipo Descripción Rango Típico Ejemplo
int Número entero -2³¹ a 2³¹-1 42, -100
float Número con decimales ±1.4E-45 a ±3.4E+38 3.14, 2.71
double Número decimal de mayor precisión ±4.9E-324 a ±1.7E+308 3.14159265
boolean Valor lógico true, false true
char Carácter individual 0 a 65535 'A', 'x'

Tipos de Datos Compuestos

Combinan tipos primitivos para crear estructuras más complejas:

  • Registros (struct/record): Agrupación de datos heterogéneos
  • Uniones (union): Comparten la misma ubicación de memoria
  • Enumeraciones (enum): Conjunto de valores nominales

Tipos Agregados o Estructuras de Datos

Colecciones de elementos del mismo tipo o de tipos diferentes:

  • Arrays: Secuencia de elementos del mismo tipo con acceso indexado
  • Listas: Secuencia flexible de elementos
  • Pilas: Acceso LIFO (Last In First Out)
  • Colas: Acceso FIFO (First In First Out)
  • Árboles: Estructura jerárquica
  • Grafos: Nodos conectados por aristas

Tipos Abstractos de Datos (TAD)

Un TAD es un modelo matemático que especifica qué datos se almacenan y qué operaciones se pueden realizar sobre ellos, abstrayéndose de la implementación específica. 

// TAD: Conjunto
TAD Conjunto
  Dominio: Conjunto de enteros
  Operaciones:
    - crearConjunto() → Conjunto
    - agregar(c: Conjunto, x: int) → Conjunto
    - contiene(c: Conjunto, x: int) → bool
    - tamaño(c: Conjunto) → int
Fin TAD

3. Datos Compuestos

Vectores (Arrays)

Un vector es una secuencia de elementos del mismo tipo almacenados en posiciones consecutivas de memoria. El acceso a cada elemento se realiza mediante un índice.

Características:

  • Acceso O(1) a elementos por índice
  • Tamaño fijo en la mayoría de lenguajes
  • Elemento en posición i está en dirección: base + (i × tamaño_elemento)

Ejemplo:

// Vector de 5 elementos enteros
int[] numeros = {10, 20, 30, 40, 50};
// Acceso: numeros[0] = 10, numeros[4] = 50

Matrices

Una matriz es un arreglo bidimensional de elementos del mismo tipo, organizado en filas y columnas.

Representación en Memoria:

  • Por filas (Row-major): Orden: M[0][0], M[0][1], M[1][0], M[1][1]
  • Por columnas (Column-major): Orden: M[0][0], M[1][0], M[0][1], M[1][1]

Ejemplo:

// Matriz 3x3
int[][] matriz = {
  {1, 2, 3},
  {4, 5, 6},
  {7, 8, 9}
};
// Acceso: matriz[1][2] = 6

Registros (Structs)

Un registro es una estructura que agrupa datos de tipos diferentes bajo un mismo nombre, permitiendo acceso a través de campos nombrados.

Ejemplo:

// Definición de un registro
struct Estudiante {
  string nombre;
  int id;
  float promedio;
};

// Uso
Estudiante est = {"Juan", 12345, 8.5};
est.promedio = 9.0;

4. Fundamentos de Algoritmia

Concepto de Algoritmo

Un algoritmo es un conjunto de instrucciones ordenadas y finitas que, tras ser ejecutadas, resuelven un problema específico.

Características de un Algoritmo:

  • Finito: Tiene un número determinado de pasos
  • Determinista: Produce el mismo resultado para las mismas entradas
  • Bien definido: Cada paso es claro e inequívoco
  • Eficiente: Resuelve el problema de forma óptima

Representación de Algoritmos

1️⃣ Lenguaje Natural

Descripción en idioma humano. Fácil de entender pero ambiguo.

2️⃣ Pseudocódigo

Mezcla de lenguaje natural y programación. Balance entre claridad y precisión.

3️⃣ Diagramas de Flujo

Representación gráfica del flujo de control. Útil para visualizar lógica.

Ejemplo: Búsqueda Lineal

Pseudocódigo:

función buscarLineal(arreglo[], objetivo):
  para i = 0 hasta longitud(arreglo) - 1:
    si arreglo[i] == objetivo:
      retornar i
  retornar -1  // No encontrado

Implementación en Python:

def buscar_lineal(arreglo, objetivo):
    for i in range(len(arreglo)):
        if arreglo[i] == objetivo:
            return i
    return -1

# Uso
resultado = buscar_lineal([10, 20, 30, 40, 50], 30)
print(resultado)  # Salida: 2

Complejidad de Algoritmos (Introducción)

La complejidad de un algoritmo mide cómo crecen sus recursos (tiempo y memoria) en función del tamaño de la entrada.

Notación Big O:

Notación Nombre Ejemplo
O(1) Constante Acceso a array por índice
O(log n) Logarítmica Búsqueda binaria
O(n) Lineal Búsqueda lineal
O(n log n) Lineal-logarítmica Merge sort
O(n²) Cuadrática Bubble sort

Ciencias de la Computación Simplificadas

Conceptos Clave:

  • Abstracción: Simplificar problemas complejos enfocándose en lo esencial
  • Modularidad: Dividir el código en componentes independientes y reutilizables
  • Recursión: Resolver problemas dividiéndolos en versiones más pequeñas del mismo problema
  • Análisis de complejidad: Evaluar eficiencia de algoritmos
  • Pruebas y validación: Verificar que el algoritmo funciona correctamente

Resumen de la Unidad 1

  • Las estructuras de datos son esenciales para organizar información eficientemente
  • Existen tipos primitivos, compuestos y abstractos de datos
  • Vectores y matrices son estructuras fundamentales para almacenamiento
  • Los algoritmos son soluciones ordenadas a problemas específicos
  • La complejidad mide la eficiencia de un algoritmo
  • La abstracción y modularidad son conceptos clave en programación
