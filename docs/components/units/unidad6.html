1. Proyectos Integradores

Proyecto 1: Sistema de Gestión de Procesos

Implementa un simulador de sistema operativo que gestiona procesos usando estructuras de datos aprendidas.

Especificación:

  • Usa Colas (FIFO) para cola de procesos listos
  • Usa Pila (LIFO) para stack de llamadas de función
  • Usa Árbol para jerarquía de procesos padre-hijo
  • Usa Grafo para dependencias entre procesos

Funcionalidades:

  • Crear nuevo proceso (Push a cola, agregar a árbol)
  • Procesar siguiente proceso (Pop de cola)
  • Cambiar prioridad (Re-ordenar cola con búsqueda)
  • Visualizar árbol de procesos (DFS/BFS)
  • Detectar deadlock (DFS en grafo de dependencias)

Complejidades Esperadas:

  • Crear: O(log n) con heap de prioridad
  • Procesar: O(1) con cola
  • Cambiar prioridad: O(n)
  • Detectar deadlock: O(V + E)

Proyecto 2: Compresor de Archivos

Implementa algoritmo Huffman para comprimir y descomprimir archivos usando árboles binarios.

Especificación:

  • Leer archivo y calcular frecuencias de cada byte
  • Construir árbol Huffman usando heap (min-priority queue)
  • Generar códigos de compresión (path en árbol)
  • Comprimir archivo reemplazando bytes con códigos
  • Descomprimir usando árbol almacenado en cabecera

Estructuras Utilizadas:

  • Tabla Hash: Frecuencias de cada byte
  • Heap: Para construir árbol Huffman
  • Árbol Binario: Estructura del árbol Huffman
  • Cola de bits: Almacenar código comprimido

Algoritmo Huffman:

def huffman_compress(datos):
    # 1. Calcular frecuencias
    freq = contar_frecuencias(datos)
    
    # 2. Crear heap con nodos
    heap = crear_heap(freq)
    
    # 3. Construir árbol
    while len(heap) > 1:
        nodo1 = heap.pop()
        nodo2 = heap.pop()
        padre = Nodo(freq=nodo1.freq+nodo2.freq,
                    izq=nodo1, der=nodo2)
        heap.push(padre)
    
    # 4. Generar códigos (DFS)
    codigos = generar_codigos(heap[0])
    
    # 5. Comprimir
    comprimido = codificar(datos, codigos)
    return comprimido, heap[0]

Proyecto 3: Red Social - Búsqueda de Influenciadores

Modela una red social como grafo y encuentra usuarios influyentes usando algoritmos de grafos.

Especificación:

  • Grafo dirigido: usuarios → seguidores
  • Encontrar influenciadores (mayor out-degree)
  • Encontrar comunidades (componentes fuertemente conexas)
  • Recomendar usuarios (BFS desde usuario actual)
  • Distancia entre usuarios (Dijkstra ponderado por interacción)

Algoritmos:

  • BFS: O(V + E) - encontrar amigos en distancia k
  • DFS: O(V + E) - explorar red desde un usuario
  • Kosaraju: O(V + E) - encontrar componentes fuertemente conexas
  • PageRank: Iterativo - medir importancia de usuarios

Proyecto 4: Sistema de Caché LRU

Implementa un caché Least Recently Used que mantiene datos accedidos recientemente con acceso O(1).

Especificación:

  • Capacidad máxima fija de elementos
  • Get: retornar valor O(1) y marcar como recientemente usado
  • Put: agregar/actualizar valor, remover LRU si necesario
  • Mantener orden de acceso (reciente al frente)

Estructuras:

  • Tabla Hash: acceso O(1) a valores
  • Lista Doblemente Ligada: mantener orden de acceso
  • Combinación: Hash table + doubly linked list

Implementación Conceptual:

class LRUCache:
    def __init__(self, capacidad):
        self.cache = {}  # Hash: clave -> nodo
        self.lista = DoublyLinkedList()  # Orden de acceso
        self.capacidad = capacidad
    
    def get(self, clave):
        if clave not in self.cache:
            return -1
        nodo = self.cache[clave]
        self.lista.mover_al_frente(nodo)
        return nodo.valor
    
    def put(self, clave, valor):
        if clave in self.cache:
            self.cache[clave].valor = valor
            self.lista.mover_al_frente(self.cache[clave])
        else:
            if len(self.cache) >= self.capacidad:
                nodo_viejo = self.lista.remover_final()
                del self.cache[nodo_viejo.clave]
            
            nodo = self.lista.agregar_al_frente(clave, valor)
            self.cache[clave] = nodo

2. Temas Especiales

Suffix Arrays y Búsqueda de Patrones

Estructura avanzada para búsqueda rápida de patrones en textos grandes.

Concepto:

  • Array de índices de todos los sufijos ordenados lexicográficamente
  • Permite búsqueda binaria de patrones: O(m log n)
  • Más simple que Suffix Trees pero O(log n) más lento

Aplicaciones:

  • Búsqueda múltiple de patrones
  • Repeticiones comunes en textos
  • Compresión de datos

Segment Trees

Estructura que permite queries y updates en rangos eficientemente.

Características:

  • Query de rango: O(log n)
  • Update puntual: O(log n)
  • Update de rango: O(log n) con lazy propagation

Operaciones Soportadas:

  • Sum, Min, Max, GCD en rangos
  • Multiplicación, XOR, conteo de elementos
  • Actualización masiva de rangos

Complejidad:

  • Construcción: O(n)
  • Query: O(log n)
  • Update: O(log n)

Trie (Árbol de Prefijos)

Estructura de árbol optimizada para almacenar y buscar strings.

Operaciones:

  • Insertar palabra: O(m) donde m es longitud
  • Buscar palabra: O(m)
  • Autocompletado: O(m + k) donde k es resultados
  • Verificar prefijo: O(m)

Aplicaciones:

  • Autocompletado en buscadores
  • Corrección de ortografía
  • Enrutamiento IP
  • Compresión de diccionarios

Ventajas sobre Tabla Hash:

  • ✅ Búsqueda por prefijos
  • ✅ Orden lexicográfico
  • ✅ Rango de palabras
  • ❌ Usa más memoria para strings cortos

Union-Find (Disjoint Set Union)

Estructura eficiente para determinar si dos elementos pertenecen al mismo conjunto.

Operaciones Principales:

  • Find: Encuentra representante del conjunto
  • Union: Combina dos conjuntos

Optimizaciones:

  • Compresión de caminos: casi O(1) amortizado
  • Unión por rango: evita árboles desbalanceados

Complejidad con ambas optimizaciones:

  • O(α(n)) amortizado, donde α es función de Ackermann inversa
  • Prácticamente O(1) para tamaños realistas

Aplicaciones:

  • Detectar ciclos en grafos: O((V + E)α(V))
  • Minimum Spanning Tree (Kruskal)
  • Conectividad de componentes

Mapa Mental: Cómo Elegir la Estructura de Datos

¿Necesitas acceso rápido a elementos?

  • Sí → Array (índice) o Tabla Hash (clave)
  • No → Lista Ligada

¿Importa el orden?

  • LIFO (último añadido primero) → Pila
  • FIFO (primero añadido primero) → Cola
  • Ordenado por prioridad → Heap

¿Relaciones entre elementos?

  • Jerarquía (padre-hijo) → Árbol
  • Conexiones complejas → Grafo

¿Muchas búsquedas de prefijos?

  • Sí → Trie
